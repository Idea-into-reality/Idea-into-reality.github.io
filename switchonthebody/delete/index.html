스위치온 바디 데이터 삭제 안내

앱: 스위치온 바디 - 다이어트 플래너 (kr.ideality.switchonthebody) · 개발자: IIRN (Idea-into-reality)

스위치온 바디는 회원가입이 없고, 이용자가 입력한 정보와 몸 사진을 개발자 서버로 보내지 않습니다. 모든 기록은 이용자 기기 안에만 저장되므로, 아래 방법으로 이용자가 직접 즉시 삭제할 수 있습니다.

앱 안에서 모두 삭제하기

1. 앱에서 설정 탭을 엽니다. 2. 맨 아래 모든 데이터 초기화를 누릅니다. 3. 확인 창에서 초기화를 누르면 바로 삭제됩니다.

앱을 삭제(제거)해도 기기 안의 모든 기록이 함께 삭제됩니다. 몸 사진은 사진 화면에서 한 장씩 지울 수도 있습니다.

삭제되는 데이터

  • 나이·성별·키·몸무게·활동량, 평일 일과
  • 일정 체크·건너뜀 기록, 직접 추가한 일정, 그날 바꾼 시간
  • 체중·체성분 기록(직접 입력하거나 Health Connect에서 가져온 값)
  • RealBody 몸 사진과 분석 결과
  • 알림 예약, 홈 화면 위젯 데이터

삭제 후 개발자가 따로 보관하는 데이터는 없습니다.

광고(Google AdMob) 관련 데이터

광고 표시를 위해 Google AdMob이 광고 ID 등 기기 정보를 처리합니다. 이 데이터는 개발자가 아니라 Google이 관리합니다. 기기 설정 > 개인정보 보호 > 광고에서 광고 ID를 재설정하거나 삭제할 수 있고, Google 데이터는 Google 계정 설정에서 관리할 수 있습니다.
